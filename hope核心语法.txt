八、完整示例
示例1：计算阶乘
hope
// 计算阶乘的函数
func factorial(n) {
    if (n == 0) {
        return 1
    }
    set result = 1
    set i = 1
    loop (i <= n) {
        set result = result * i
        set i = i + 1
    }
    return result
}

// 主程序
set num = input("请输入一个正整数:", int)
if (num >= 0) {
    set fact = factorial(num)
    show(num, "的阶乘是:", fact)
}
else {
    show("请输入非负整数!")
}
示例2：列表操作

示例3：猜数字游戏
hope
import random

func guess_number() {
    set secret = randint(1, 100)
    set attempts = 0
    set guessed = false
    
    show("猜数字游戏开始！范围是1-100")
    
    loop (!guessed) {
        set guess = input("请输入你的猜测:", int)
        set attempts = attempts + 1
        
        if (guess == secret) {
            show("恭喜！猜对了！")
            show("你用了", attempts, "次猜中")
            set guessed = true
        }
        else if (guess > secret) {
            show("太大了！")
        }
        else {
            show("太小了！")
        }
    }
}

九、语法特点总结
简洁性：语法类似 JavaScript/Python 的混合

强类型：支持 int、float、str、list 等类型

函数式特性：支持函数作为一等公民

扩展性：可通过 import 导入扩展模块

安全性：内置错误处理机制

交互性：支持 REPL 交互式环境

十、语法注意事项
变量必须先声明后使用

语句以换行分隔，不需要分号

代码块用花括号 {} 包裹

函数必须有明确的 return 语句

列表索引从 0 开始

字符串用双引号包裹

注释支持单行 // 和多行 /* */

这就是 Hope 语言的核心语法规范。它具有现代编程语言的主要特性，同时保持了简洁性和易用性。
